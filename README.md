### **✍️ About the Project**
This hosts the source code for the digital platform where the author’s lines of research and essays are documented. The site’s design reflects the author’s philosophy: a minimalist typographic approach, clear information architecture, and an aesthetic focused on extended reading and documentary rigor.

### 🛠️ Tech Stack
The site is built using standard web technologies, prioritizing accessibility, performance, and typographic design. All with the help of *Claude Code*:

Semantic HTML5: Clear and meaningful structure.
CSS3: Minimalist design with a carefully selected color palette (#F2EEE7, #2E2B28).
JavaScript (Vanilla): Lightweight interactivity, including constellation animations on the hero canvas.
Typography: Cormorant Garamond (headings and body text) and IBM Plex Mono (details and markers).
SEO and Metadata: Integration of Open Graph, Schema.org (@type: “Person”), and canonical links.
Accessibility (a11y): Inclusion of skip links, ARIA attributes, and support for screen readers.

### 🚀 Local Use and Deployment
If you want to clone this repository to review the code or design locally:

Clone the repository:
```bash
git clone https://github.com/condor-andino/condor-andino.github.io
```
Navigate to the project directory:
```bash
cd condor-andino.github.io
```

Open the index.html file in your preferred browser.
Note: No Node.js dependencies or compilers are required.
